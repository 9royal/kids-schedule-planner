# 兒童/學生自主學習視覺化作息規劃系統 (Kids Schedule Planner)

適合國中小學生在筆電與 iOS（iPad / iPhone Safari）流暢運作的自主學習作息規劃系統。

## ✨ 核心特色

1. **日常時間、現在活動與排行榜首頁 (`DualClockDashboard` + `LeaderboardPanel`)**
   - **SVG 向量指針圓鐘**與 **24 小時制數位時鐘**。
   - **當前活動狀態卡**：台灣國小標準**直式注音**排版 + 英文名稱 + 手繪風可愛 SVG 圖示。
   - **雲端多維度排行榜**：支援設定個人暱稱或自動將姓名中間字改為 `○`（如 `林○宇`），並於每個榜單顯示專屬暖心哲思與格言佳句。
2. **24H 拼圖式全週作息規劃表 (`WeeklyPuzzlePlanner`)**
   - 獨立於「規劃作息表」分頁，不顯示上方時鐘與現在活動，釋放 100% 排課空間。
   - 支援手動調整聚焦起訖時間，且全天 `00:00–24:00`（含非聚焦時段）皆可點擊或拖放連接積木。
3. **Google 行事曆 & `.ics` 智慧匯入模組 (`CalendarImportModal`)**
   - 內建完整圖文教學手冊、範例 `.ics` 下載、Google OAuth 2.0 (`events.list`) 與 `ical.js` 智慧關鍵字 8 大類歸納。
